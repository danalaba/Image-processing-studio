# Майбутній балансувальник

На етапі 5 тут з’явиться конфігурація Nginx з upstream для api-1 та api-2.
Зараз Nginx не налаштований і балансування не реалізоване.

Для демонстрації знадобляться дві окремі перевірки:
1. HTTP-запити через Nginx отримують різні instance_id від двох API.
2. Кілька фонових задач виконуються на двох Celery workers; докази — job ID,
   worker ID та журнали. Один job автоматично між workers не ділиться.

Обидва API повинні використовувати спільні PostgreSQL, Redis і файловий том.
Не зберігати історію задач у Python-списку чи локальні результати лише в одному контейнері.
